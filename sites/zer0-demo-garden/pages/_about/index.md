# About

I read a lot and forget most of it, so I started writing notes that link to each other. This is that pile, in public.

The notes are deliberately short. When one grows past a screen it usually means it contains two ideas and wants splitting, which is the only real rule here.

Nothing is finished. If a note contradicts another note, both are staying up until I work out which one is wrong.
