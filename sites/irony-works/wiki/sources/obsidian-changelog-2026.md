# Obsidian Changelog 2026

Primary release record. Used to date platform capabilities rather than trusting secondary summaries.

## Key Claims

- The Obsidian CLI ships as a **standalone binary in v1.12.7 Desktop (2026-03-23)**; before that, callers invoked the Electron binary directly. The standalone binary is credited with "significantly faster terminal interactions" (confidence: high).
- **v1.13.0 (2026-05-28)** is a major release carrying a settings redesign and Bases table-view column resizing (confidence: high).
- Bases development continues through the 1.13 line: formula editor in pop-out windows, sort filter UI, and file link display in **v1.13.2 (2026-07-14)**; automatic column sizing and formula editor fixes in **v1.13.4 (2026-07-27)** (confidence: high).
- Desktop shipped at a steady cadence in 2026: 1.12.6 (Mar 18), 1.12.7 (Mar 23), 1.13.0 (May 28), 1.13.1 (Jun 9), 1.13.2 (Jul 14), 1.13.3 (Jul 21), 1.13.4 (Jul 27), 1.13.5 (Aug 5), 1.13.6 (Aug 7) (confidence: high).

## What This Contributes

Two things the ecosystem write-ups get wrong or blur.

First, the CLI date. The distinction between "introduced in 1.12" and "standalone binary in 1.12.7" is the source of the conflicting February/March claims in circulation.

Second, Bases is under active iteration a year after launch — three releases in the 1.13 line touch it. Bases is not a shipped-and-parked feature, which matters for any agent skill that generates `.base` files against a moving syntax.

> [!gap] The fetched changelog content did not mention Cards, List, or Map view types. Secondary sources place Table and Cards in 1.9 and List and Map in 1.10 (2025 releases, outside this changelog window). Unverified against primary source.
