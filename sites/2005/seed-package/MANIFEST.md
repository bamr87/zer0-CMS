# Seed Package Manifest

The package body **is** the framework layer of this repository — this manifest names it rather
than duplicating it. Copy every *Load-bearing* file verbatim into the first repo of a new
lineage; create `lifecycle.yml` from the template; copy nothing from *Regenerable*.

Birth requirement (proven by two replants in this lineage): **framework + lifecycle.yml only.**
Everything else — seed, README, roadmap, content, structure — the repo grows itself via
`/genesis` and the daily tick.

## Load-bearing (copy verbatim)

### Root

| File | Role |
|---|---|
| `CLAUDE.md` | Operating manual every agent session loads: generated-vs-hand-authored map, delegation hierarchy, publish gate, conventions. |
| `LIFECYCLE.md` | Lifecycle design doc: grow → replant → consolidate, shepherd fallback, pollination, secrets/scopes setup. |
| `.gitignore` | Excludes local Claude settings and worktrees from the repo. |
| `lifecycle.yml` | **From template, hand-filled** — policy knobs + lineage state. The one file you configure. |

### `.github/workflows/` — the heartbeat

| File | Role |
|---|---|
| `workflows/grow.yml` | Daily cron running one lifecycle-gated tick via `claude-code-action`; encodes the hard-won fixes (PAT routing around token override, credit-exhaustion fallback detection, id-token permission, allowed tools, phase/model resolver). |

### `.github/prompts/` — the verbs (canonical procedures)

| File | Role |
|---|---|
| `prompts/genesis.prompt.md` | Bootstrap a fresh repo for any concept; successor-germination mode derives the concept from lifecycle.yml. |
| `prompts/grow.prompt.md` | One growth tick: plan → content + structure → verify → record → publish. |
| `prompts/replant.prompt.md` | Close a generation, spawn + germinate the successor, register it in the driver's lineage registry. |
| `prompts/consolidate.prompt.md` | Merge a completed lineage into one range-named repo; archive members. |
| `prompts/distill.prompt.md` | One-time frontier-model lineage meta-review; produces/refreshes this package. |
| `prompts/deep-dive.prompt.md` | Research one topic in depth → dedicated article file. |
| `prompts/update-readme.prompt.md` | Bulk-populate knowledge-table rows from gaps or a list. |
| `prompts/evolve.prompt.md` | Audit & improve the customization layer itself. |
| `prompts/encode-seed.prompt.md` | Append a session entry to seed.md §8 (the genesis record). |
| `prompts/publish.prompt.md` | Thin wrapper over the publish-session skill. |

### `.github/skills/` — the mechanisms

| File | Role |
|---|---|
| `skills/check-lifecycle/SKILL.md` | Tick gate: counts §8 ticks, decides grow / replant / consolidate / dormant. |
| `skills/research/SKILL.md` | Source-verified fact gathering; writes nothing. |
| `skills/add-topic/SKILL.md` | Research → row-vs-file decision → create → link. |
| `skills/build-structure/SKILL.md` | Idempotent generation of indices, TIMELINE, INDEX, cross-refs inside markers. |
| `skills/plan-roadmap/SKILL.md` | Picks the next 1–3 items; rewrites ROADMAP.md. |
| `skills/sync-seed/SKILL.md` | Regenerates seed.md §1–7 from live repo state. |
| `skills/publish-session/SKILL.md` | The only sanctioned push path: encode-seed → review → commit → push. |
| `skills/pollinate/SKILL.md` | Bidirectional framework convergence across the lineage via auto-merged PRs. |

### `.github/agents/` + `.github/instructions/`

| File | Role |
|---|---|
| `agents/architect.agent.md` | Orchestrator: runs the tick pipeline, delegates content to Curator. |
| `agents/curator.agent.md` | Content specialist: research + write within the concept. |
| `instructions/content.instructions.md` | Content standards: scope, two-source rule, table/file formats, tone. |
| `instructions/agents.instructions.md` | Conventions for authoring agent files (tools, sections, delegation). |

### `.claude/` — Claude Code adapters (copy the whole directory)

| Path | Role |
|---|---|
| `.claude/commands/*.md` | Native slash commands; each delegates to its canonical `.github/prompts/` file. |
| `.claude/agents/{architect,curator}.md` | Subagent definitions mirroring `.github/agents/`. |
| `.claude/skills/*/SKILL.md` | Skill adapters pointing at the canonical `.github/skills/` procedures. |

## Regenerable (do NOT copy — the repo grows these itself)

| File | Regenerated by |
|---|---|
| `seed.md` | `/genesis` (§1, §8 genesis entry), then `sync-seed` (§1–7 every tick). |
| `README.md` | `/genesis` (starter knowledge table), then curator/add-topic. |
| `ROADMAP.md` | `plan-roadmap`, every tick. |
| `TIMELINE.md`, `INDEX.md`, `<category>/index.md`, `## Related` blocks | `build-structure`. |
| `<category-slug>/*.md` topic files | curator / deep-dive. |
| `seed-package/` | `/distill` (the driver repo only). |

## Not part of the package

| Item | Why |
|---|---|
| Secrets (`ANTHROPIC_API_KEY`, `LIFECYCLE_PAT`, `CLAUDE_CODE_OAUTH_TOKEN`) | Set as **org** secrets — see `README.md` here. |
| Any content, structure, or seed inventories from the source instance | Carrying them along was never needed at birth; genesis regrows everything from the Concept Definition. |
