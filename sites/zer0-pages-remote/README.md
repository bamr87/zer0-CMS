# zer0-pages-remote

> **Live showcase** of the [zer0-mistakes](https://github.com/bamr87/zer0-mistakes)
> Jekyll theme installed via the **remote install profile** — no theme source
> code in this repo, just configuration. Layouts, includes, assets, and styles
> are pulled at build time from the upstream theme.

## What this repo demonstrates

This is a **reference implementation** showing the smallest possible site that
consumes [`bamr87/zer0-mistakes`](https://github.com/bamr87/zer0-mistakes) as a
remote theme. Use it as a copy-paste starting point, or fork it directly.

| Capability | How it's wired |
|---|---|
| **Remote theme loading** | `remote_theme: bamr87/zer0-mistakes` in [`_config.yml`](_config.yml) — no `_layouts/`, `_includes/`, `_sass/`, or `assets/` checked in |
| **GitHub Pages CI/CD** | [`.github/workflows/jekyll-gh-pages.yml`](.github/workflows/jekyll-gh-pages.yml) builds with Bundler on push to `main` and publishes `_site/` to `gh-pages` |
| **Codespaces ready** | [`.devcontainer/devcontainer.json`](.devcontainer/devcontainer.json) — Ruby + Jekyll auto-bootstrap in the cloud |
| **AI agent guidance** | [`AGENTS.md`](AGENTS.md) + [`.github/copilot-instructions.md`](.github/copilot-instructions.md) + [`.github/instructions/`](.github/instructions/) + [`.github/prompts/`](.github/prompts/) |
| **Starter content** | `pages/` with `_posts/`, `_docs/`, `_about/`, `blog.md`, `quickstart.md` — all render through the remote theme's layouts |

## How this site was created

Every file in this repo (except this README) was generated by the modular
installer in the upstream theme:

```bash
# From a clone of bamr87/zer0-mistakes:
./scripts/bin/install init   --profile remote --non-interactive \
    --site-name "zer0-pages-remote" --github-user "bamr87"      \
    --author    "Amr Abdel-Motaleb"  --email "amr@zer0-mistakes.com" \
    /path/to/zer0-pages-remote

./scripts/bin/install deploy github-pages /path/to/zer0-pages-remote
./scripts/bin/install agents             /path/to/zer0-pages-remote --force
./scripts/bin/install doctor             /path/to/zer0-pages-remote
```

You can also bootstrap the **same** scaffold over `curl | bash`:

```bash
curl -fsSL https://raw.githubusercontent.com/bamr87/zer0-mistakes/main/install.sh \
  | bash -s -- --remote --non-interactive \
    --site-name "my-site" --github-user "myname"
```

See the upstream installer reference:
[`bamr87/zer0-mistakes` → `scripts/bin/install`](https://github.com/bamr87/zer0-mistakes/blob/main/scripts/bin/install).

## Repo layout

```
zer0-pages-remote/
├── _config.yml                     # remote_theme directive + site identity
├── Gemfile                         # github-pages + jekyll-remote-theme
├── index.md                        # home page (uses remote theme layouts)
├── 404.html                        # graceful 404
├── _data/
│   ├── authors.yml                 # author metadata referenced by posts
│   └── navigation/main.yml         # top-nav menu
├── pages/                          # all writable content lives here
│   ├── _posts/                     # blog posts
│   ├── _docs/                      # docs collection
│   ├── _about/                     # about pages + settings reference
│   ├── blog.md                     # blog index
│   └── quickstart.md               # quickstart landing
├── .github/
│   ├── workflows/jekyll-gh-pages.yml   # CI: build + publish
│   ├── copilot-instructions.md         # main AI agent instructions
│   ├── instructions/*.md               # file-scoped instruction sets
│   └── prompts/*.md                    # reusable agent prompts
├── .devcontainer/devcontainer.json     # Codespaces config
└── AGENTS.md                           # cross-tool AI agent entry point
```

**Notably absent** (and that's the point of `remote_theme`):
`_layouts/`, `_includes/`, `_sass/`, `assets/`, `_plugins/`. They live in
`bamr87/zer0-mistakes` and are pulled at build time.

## Local development

### Option A — Codespaces (zero setup)

Click the badge at the top of this README. Jekyll starts automatically and the
preview opens in a forwarded port.

### Option B — Local Ruby

```bash
bundle install
bundle exec jekyll serve
# → http://localhost:4000/zer0-pages-remote/
```

### Option C — Docker

This repo is intentionally Docker-free to keep the example small. To preview
locally with Docker, copy the upstream theme's `docker-compose.yml`:

```bash
curl -fsSL https://raw.githubusercontent.com/bamr87/zer0-mistakes/main/docker-compose.yml -o docker-compose.yml
docker compose up
```

## Customising the showcase

1. Edit `_config.yml` → set `title`, `subtitle`, `description`, `url`, `baseurl`.
2. Add posts to `pages/_posts/` (filename pattern `YYYY-MM-DD-slug.md`).
3. Add docs to `pages/_docs/`.
4. Edit `_data/navigation/main.yml` to wire your own nav.
5. Push to `main` — the workflow rebuilds and publishes to GitHub Pages
   automatically.

To **upgrade** to a richer scaffold (admin settings, full starter content),
re-run the installer with a different profile:

```bash
./scripts/bin/install init --profile fork  /path/to/zer0-pages-remote
# or
./scripts/bin/install init --profile full  /path/to/zer0-pages-remote
```

See `./scripts/bin/install list-profiles` for the full menu.

## AI agent integration

This repo ships the same agent guidance contract as the upstream theme:

- **[`AGENTS.md`](AGENTS.md)** — cross-tool entry point (Copilot, Codex, Cursor,
  Aider, Jules, Continue, Claude Code).
- **[`.github/copilot-instructions.md`](.github/copilot-instructions.md)** —
  detailed Copilot instructions (front-matter standards, branching, releases).
- **[`.github/instructions/`](.github/instructions/)** — file-scoped instruction
  sets activated by `applyTo:` glob patterns (layouts, includes, scripts,
  tests, docs, version control, install).
- **[`.github/prompts/`](.github/prompts/)** — reusable agent prompts
  (commit-publish pipeline, front-matter audit, full-rebuild blueprint).

Open this repo in any agent-aware editor and the relevant guidance loads
automatically.
