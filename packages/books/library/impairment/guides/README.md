# Drafting guides

One guide per act, holding the beats, hooks and continuity rules for that group of chapters. Read the guide covering your chapter before you write it, along with the chapters either side.

| Guide | Chapters | Act |
| --- | --- | --- |
| [`act-1-chapters-01-05.md`](act-1-chapters-01-05.md) | 1–5 | The Legacy and the Lie |
| [`act-2-chapters-06-09.md`](act-2-chapters-06-09.md) | 6–9 | The Breakdown |
| [`act-3-chapters-10-14.md`](act-3-chapters-10-14.md) | 10–14 | Revelation and Reckoning |

These were written before the draft existed and parts of them have been overtaken by it — the act-1 guide asks for first person, for one. Where a guide and the draft disagree, [`../notes/continuity.md`](../notes/continuity.md) records the open question. Resolve it there, then update the guide.
