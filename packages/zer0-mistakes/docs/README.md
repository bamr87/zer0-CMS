# zer0-mistakes documentation

> Every contributor and maintainer document in the theme, one line each — the published user guides live in `pages/_docs/`, and AGENTS.md says how to work here.

These are the technical docs: architecture, the installer's internals, release and propagation systems, the styling reference, and the generated [command](reference/commands.md), [installer](reference/installer.md), [workflow](reference/workflows.md) and [agent-guidance](reference/agent-guidance.md) references. They are excluded from the Jekyll build. What a theme *user* reads — installation, features, customization, deployment — is in [`pages/_docs/`](../pages/_docs/), published at [zer0-mistakes.com/docs/](https://zer0-mistakes.com/docs/); link there rather than restating it. The live theme preview is at `/about/settings/theme-preview/` on a built site.

To add a document, start from [the feature template](templates/feature-documentation-template.md), give it the front matter `./scripts/docs/lint-frontmatter.sh` requires (its `description:` becomes its row below), then run `python3 tools/docs_index.py --write` from the theme's root. Release history belongs in [`CHANGELOG.md`](../CHANGELOG.md).
